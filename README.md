# Bit by Bit Prep

Coding-interview practice site: Chinese explanations, step-by-step algorithm animations, and Python problems (easy to medium) that run and are graded in the browser with [Pyodide](https://pyodide.org/).

Chapters cover bit manipulation, arrays and two pointers, strings, hash maps, sliding window, stacks and queues, linked lists, binary search, sorting, recursion, trees, graphs, heaps and dynamic programming, plus C / systems concept questions and English interview phrasing.

Open `index.html` through any static web server (GitHub Pages works). Progress and code drafts are stored only in your own browser.
